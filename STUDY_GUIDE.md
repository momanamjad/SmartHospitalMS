## 1. OOP Concepts used in this project

### what is a class?
A class is a blueprint or a template for creating objects. It defines data (properties) and behavior (methods).
*   **Example:** `Patient.cs` (found in `Models.cs`)
```csharp
public class Patient : BaseEntity
{
    public string FullName { get; set; } // Property (Data)
    public int Age { get; set; }         // Property (Data)
    
    public override string GetSummary()   // Method (Behavior)
    {
        return $"Patient: {FullName}, Age: {Age}";
    }
}
```

### What is inheritance?
Inheritance allows a class (child) to acquire the properties and methods of another class (parent). It promotes code reuse.
*   **Example:** `BaseEntity` → `Patient`
`BaseEntity` contains common fields like `ID` and `CreatedAt`. By inheriting from it, `Patient`, `Doctor`, and `User` all get these fields automatically.
```csharp
public abstract class BaseEntity { ... } // Parent
public class Patient : BaseEntity { ... } // Child inherits ID, CreatedAt
```

### What is encapsulation?
Encapsulation is hiding the internal details of an object and providing access only through public properties or methods. It protects the data.
*   **Example:** Private fields with public properties in `BaseEntity.cs`
```csharp
private DateTime _createdAt; // Private field (hidden)

public DateTime CreatedAt // Public property (exposed access)
{ 
    get => _createdAt; 
    set => _createdAt = value; 
}
```

### What is polymorphism?
Polymorphism means "many forms." It allows a method to behave differently based on the object calling it. We use the `virtual` keyword in the parent and `override` in the child.
*   **Example:** `GetSummary()` method.
In `BaseEntity`, it returns a generic ID. In `Patient`, it is overridden to return the patient's name and age.
```csharp
// In BaseEntity:
public virtual string GetSummary() { return $"Entity ID: {ID}"; }

// In Patient:
public override string GetSummary() { return $"Patient: {FullName}"; }
```

## 2. C# Specific Concepts

### What is a static class?
A static class cannot be instantiated (you can't use `new`). It is used for utility functions that don't need to store object-specific state.
*   **Example:** `DatabaseHelper` is static because we just need its methods to talk to the DB; we don't need "multiple copies" of it.
```csharp
public static class DatabaseHelper { ... }
```

### What is a partial class?
A partial class allows you to split a single class definition across multiple files. In WinForms, one file (`Form1.cs`) holds your logic, and another (`Form1.Designer.cs`) holds the UI code generated by Visual Studio.
*   **Example:** `public partial class LoginForm : Form`

### What is a using block?
A `using` block ensures that "disposable" objects (like database connections or file streams) are closed and cleaned up automatically, even if an error occurs.
*   **Example:** In `DatabaseHelper.cs`
```csharp
using (SqlConnection conn = GetConnection())
{
    // Connection is automatically closed at the end of this block
}
```

### What is try-catch?
It is used for **Exception Handling**. The `try` block contains code that might fail, and the `catch` block handles the error gracefully without crashing the app.
*   **Example:** 
```csharp
try {
    DatabaseHelper.ExecuteNonQuery(query);
} catch (Exception ex) {
    MessageBox.Show("Error: " + ex.Message);
}
```

### What is an event handler?
An event handler is a method that "listens" for a user action (like a click) and runs code in response.
*   **Example:** `BtnLogin_Click` in `LoginForm.cs`
```csharp
btnLogin.Click += BtnLogin_Click; // Wiring the event

private void BtnLogin_Click(object sender, EventArgs e) {
    // Logic to run when button is clicked
}
```

## 3. Database Concepts

### What is a primary key?
A unique identifier for every record in a table. It cannot be null and cannot be duplicated.
*   **Example:** `UserID` in `Users` table, `PatientID` in `Patients` table.

### What is a foreign key?
A field in one table that links to the Primary Key of another table. It creates a relationship between tables.
*   **Example:** `PatientID` in the `Appointments` table refers to `PatientID` in the `Patients` table.

### What is a normalized database?
Normalization is the process of organizing data to reduce redundancy. Our DB is normalized because we don't store Patient names in the Appointments table; we only store the `PatientID`.

### What is SQL Injection?
A security attack where a hacker enters malicious SQL code into an input field.
*   **How we prevent it:** We use `SqlParameter`. Instead of putting text directly into the query, we use placeholders like `@user`.
```csharp
string query = "SELECT * FROM Users WHERE Username = @user";
SqlParameter[] parameters = { new SqlParameter("@user", username) };
```

### SQL Queries used in this project:
1.  **SELECT:** `SELECT * FROM Patients` (Fetch data)
2.  **INSERT:** `INSERT INTO Patients (FullName) VALUES (@name)` (Add data)
3.  **UPDATE:** `UPDATE Patients SET FullName=@name WHERE PatientID=@id` (Modify data)
4.  **DELETE:** `DELETE FROM Patients WHERE PatientID=@id` (Remove data)

## 4. ADO.NET Concepts

ADO.NET is the part of .NET used to interact with databases.
*   **SqlConnection:** The bridge/pipe to the SQL Server.
*   **SqlCommand:** The actual SQL statement you want to run.
*   **SqlDataAdapter:** A bridge that pulls data from the DB and fills it into a `DataTable`.
*   **DataTable:** An in-memory table that holds data (like a spreadsheet in RAM).
*   **ExecuteNonQuery:** Used for INSERT, UPDATE, DELETE (returns number of rows affected).
*   **ExecuteScalar:** Used for queries that return a single value (e.g., `COUNT(*)`, `MAX(ID)`).
*   **ExecuteReader:** Used for reading rows one by one (though we mostly use `DataTable` for simplicity).

## 5. Security Concepts

### What is SHA-256 Hashing?
Hashing turns a password into a fixed-length string of random characters. It is **one-way** (you cannot "un-hash" it).
*   **Example:** In `SecurityHelper.cs`, we hash passwords so even if the database is stolen, the hacker cannot see the real passwords.

### Hashing vs. Encryption
*   **Hashing:** One-way (used for passwords).
*   **Encryption:** Two-way (can be decrypted with a key; used for sensitive messages).

### Session Management
The `Session.cs` class stores the `CurrentUser` after a successful login. This allows the app to know who is logged in and what their `Role` (Admin, Doctor, etc.) is across different forms.

## 6. Collections and LINQ

### List<T>
A dynamic array that can grow in size. Used in `PatientForm.cs` to hold all patient objects.
```csharp
private List<Patient> allPatients = new List<Patient>();
```

### LINQ (Language Integrated Query)
LINQ allows you to filter and search collections using a SQL-like syntax in C#.
*   **Example:** Searching for a patient by name in `PatientForm.cs`:
```csharp
// Line by line explanation:
var filtered = allPatients.Where(p => 
    p.FullName.Contains(search, StringComparison.OrdinalIgnoreCase) || // Check if name contains search text
    p.Contact.Contains(search) // OR check if contact contains search text
);
```

## 7. Windows Forms Concepts

*   **Form:** A window in the application. Unlike a React component (which is web-based), a Form is a native Windows window.
*   **DataGridView:** A grid control used to display tables of data. We bind it using `dgv.DataSource = data`.
*   **Timer:** A control that runs code at intervals. Used for the clock in `Dashboard.cs`.
*   **Show() vs ShowDialog():**
    *   `Show()`: Opens a window and lets you click back on the old one.
    *   `ShowDialog()`: Opens a window and **blocks** you from clicking the old one until the new one is closed (used for popups).
*   **Dock vs Anchor:**
    *   **Dock:** Sticks a control to an edge (Top, Left, Fill). Used for the Side Menu.
    *   **Anchor:** Keeps a control at a fixed distance from edges when the window is resized. Used for the Search bar.

## 9. 20 Possible Exam Questions & Answers

1.  **Q: Why is DatabaseHelper static?**
    *   A: Because it provides utility methods (connecting to DB) that don't need object-specific data. It saves memory and is easy to access globally.
2.  **Q: What happens if you don't close a SqlConnection?**
    *   A: It causes a "Connection Leak." Eventually, the database will run out of available connections and stop responding to the app.
3.  **Q: Why hash passwords instead of encrypting them?**
    *   A: Hashing is more secure because it cannot be reversed. Even the Admin cannot see a user's password.
4.  **Q: What is the purpose of the Session class?**
    *   A: To store the identity and role of the logged-in user so we can restrict access (e.g., Doctors can't see Billing).
5.  **Q: Explain the token generation logic.**
    *   A: We fetch the maximum `AppointmentID`, add 1 to it, and format it as `APT-XXXX` using `nextID.ToString("D4")`.
6.  **Q: What does ON DELETE CASCADE mean?**
    *   A: If a Patient is deleted, all their Appointments and Bills are automatically deleted by the database to prevent orphaned records.
7.  **Q: Difference between `ExecuteNonQuery` and `ExecuteScalar`?**
    *   A: `ExecuteNonQuery` returns the number of rows changed; `ExecuteScalar` returns the first value of the first row (like a Count).
8.  **Q: Why use `using` blocks for SQL commands?**
    *   A: To ensure `Dispose()` is called, which releases unmanaged resources like database handles immediately.
9.  **Q: How does the application prevent SQL Injection?**
    *   A: By using `SqlParameter` objects instead of string concatenation in queries.
10. **Q: What is a `DataTable`?**
    *   A: An in-memory object that represents a database table, used to hold query results before showing them in a Grid.
11. **Q: How does `dgv.DataSource` work?**
    *   A: It maps the properties of a list (or rows of a DataTable) directly to the columns of the DataGridView.
12. **Q: What is the use of `abstract` in `BaseEntity`?**
    *   A: It prevents anyone from creating a "BaseEntity" object directly. You can only create "Patients" or "Doctors."
13. **Q: What is `partial class`?**
    *   A: Splitting a class into two files, allowing UI code and Logic code to stay separate.
14. **Q: How is the Clock updated every second?**
    *   A: Using a `System.Windows.Forms.Timer` with an `Interval` of 1000ms.
15. **Q: What is the role of `App.config`?**
    *   A: It stores the `connectionString` so it can be changed without re-compiling the entire code.
16. **Q: How do you handle database errors?**
    *   A: Using `try-catch` blocks around database calls to show a user-friendly message instead of a crash.
17. **Q: What is the difference between `List<T>` and a standard Array?**
    *   A: `List<T>` is dynamic (can change size), while an Array has a fixed size defined at creation.
18. **Q: Where is LINQ used in this project?**
    *   A: In `PatientForm.cs` to filter the `allPatients` list based on what the user types in the search box.
19. **Q: What is a "Constructor"?**
    *   A: A special method (e.g., `public Patient()`) that runs automatically when an object is created to initialize its values.
20. **Q: What is the purpose of `SqlDataAdapter`?**
    *   A: It acts as a middleman that runs a `SqlCommand` and fills the results into a `DataTable`.
